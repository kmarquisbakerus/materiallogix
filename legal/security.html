Security

Effective August 2026 · MaterialLogix Studio™ is a product of LIBRASIDE TECHNOLOGIES LLC

Reporting a vulnerability

Found something? Email admin@materiallogix.com with "SECURITY" in the subject. We respond within 72 hours, credit researchers who want credit, and never pursue good-faith research legally.

Scope

This website, the license verification endpoint, and the shipped applications. The engines run locally on user machines; vulnerabilities in upstream open-source components should also go to those projects.

Design posture

Local network. Phone control over Wi-Fi is off by default. When on, the connection is encrypted (TLS) and gated by a high-entropy access token carried in the pairing code; repeated wrong tokens lock the caller out, and only this computer's own addresses are accepted. The desktop bridge otherwise serves the local machine only.

The product is local-first: local creative files stay on the user's device. Account, license, billing, privacy-choice, security, cloud-job, and user-approved optional diagnostic records are separated by purpose and protected with least-privilege access. Optional diagnostics exclude media, prompts, scripts, filenames, project names, free-form error text, and voice recordings. Cloud jobs are packaged, authorized, metered, and stored separately from account credentials.
